# Pivot Triggers — #001 Harness Plugin MVE

> 사이클 중 *어떤 신호*가 보이면 pivot을 고려하는가. 신호 → pivot 타입 매핑 (`07 §7.6`).

| 신호 (사이클 중 관찰) | Pivot 타입 | 구체 행동 |
|---|---|---|
| 게이트 스킬을 만들다 보니 *09 체크리스트 자체가 dev-tool에 안 맞음* | **Zoom-in pivot** | MVE를 "dev-tool/self 사이클 타입"을 09에 추가하는 것으로 좁힘 |
| 대화형 게이트가 매번 너무 김 (시나리오 3) | **Platform pivot** | 대화형 → *정적 체크리스트 + 1개 판단 질문*으로 경량화 |
| 플러그인 골격 만들기가 1세션 다 먹음 | **Scope-down** | 스킬 1개 대신 *cycle-init.py를 직접 실행하는 단일 커맨드*로 축소 |
| self-test가 "이미 이 사이클이 게이트를 수동 통과함"을 보여줌 → 자동화 가치 의심 | **Kill 후보** | H2 재검토 — 수동이 충분하면 자동화 불필요 |

## Pivot vs Kill 구분
- 위 1-3은 *같은 문제(자기 사이클 완주 도구)* 안에서의 방향 전환 → pivot
- 4번은 *문제 자체의 소멸* (수동으로 충분) → kill 후보, 도피 아님
