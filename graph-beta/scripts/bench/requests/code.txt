This repository is a Node 22 monorepo `ledger`: the root package.json declares workspaces packages/* and `npm test` runs `node --test` over every package; each package has its own package.json, a stub src/index.mjs and a smoke test. Implement the personal expense tracker across the four packages, as ES modules with no dependencies and relative imports between packages (e.g. `../../csv/src/index.mjs`; no npm install): (a) packages/csv — parse CSV expense rows (date, amount, merchant, memo) into records with validation and typed errors (bad date, bad amount, wrong column count); (b) packages/rules — a categorization rule engine: ordered rules {match: substring or regex on merchant, category}, first match wins, default "uncategorized", plus loading rules from a JSON file; (c) packages/report — monthly report: totals per category per month, top 3 merchants by spend, and a plain-text table renderer; (d) packages/cli — bin/ledger.mjs, the CLI `ledger report <csv> --rules <json> [--month YYYY-MM]` wiring the three together, exit code 1 with a message on invalid input. Each package gets real node:test tests under its own test/, the root README.md documents usage with an example CSV and rules file, and `npm test` at the root must pass at the end.
