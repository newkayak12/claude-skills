In this empty Node 22 project (package.json exists, tests run with `npm test` = `node --test`), build `ledger`, a personal expense tracker library plus CLI, as ES modules with no dependencies: (a) src/csv.mjs — parse CSV expense rows (date, amount, merchant, memo) into records with validation and typed errors (bad date, bad amount, wrong column count); (b) src/rules.mjs — a categorization rule engine: ordered rules {match: substring or regex on merchant, category}, first match wins, default "uncategorized", plus loading rules from a JSON file; (c) src/report.mjs — monthly report: totals per category per month, top 3 merchants by spend, and a plain-text table renderer; (d) bin/ledger.mjs — CLI `ledger report <csv> --rules <json> [--month YYYY-MM]` wiring the three together, exit code 1 with a message on invalid input. Each module gets its own node:test file under test/, README.md documents usage with an example CSV and rules file, and `npm test` must pass at the end.
