Build `ledger`, a personal expense tracker, in this Node 22 monorepo (root package.json with workspaces packages/*; `npm test` runs `node --test`; the four workspace packages are stubs you may rename, merge or split). It must import bank CSV exports, categorize each expense by user-defined rules, and report monthly spending from the command line. You decide the package split, the module contracts, the CLI shape, the error handling and the tests; ES modules, no dependencies, relative imports between packages. When you are done, a new user must be able to follow the root README from a CSV file to a monthly report, and `npm test` must pass.
