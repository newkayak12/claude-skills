# claude-skills

A Claude Code plugin marketplace with 25 skills for software engineering.

## Install via Claude Code

```
/plugin marketplace add https://github.com/newkayak12/claude-skills.git
/plugin install newkayak12-skills@newkayak12-claude-skills
```

See [plugins/newkayak12-skills/README.md](./plugins/newkayak12-skills/README.md) for the full list.
