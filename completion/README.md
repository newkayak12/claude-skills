# completion

Stand up a verify-level, then confirm it with an isolated subagent — independent evidence before any success claim.

## Install & Uninstall

```bash
# Install
/plugin install completion@newkayak12-claude-skills

# Uninstall
/plugin uninstall completion@newkayak12-claude-skills
```

## Skills

| Skill | Description |
|-------|-------------|
| `verification-before-completion` | Stand up a pass bar, then verify it with an isolated subagent so the check is independent of the context that did the work |
