In this empty Node 22 project (only a README.md exists), build a de-duplication helper as an ES module with no dependencies. Create package.json with `"type": "module"` and a `test` script `node --test`. Create src/dedupe.mjs exporting `dedupeById(records)`, where records is an array of objects that each have an `id`. The function returns the very same array object that was passed in, with every later record that repeats an earlier id removed, keeping the first record of each id in its original order. The function must never modify the array it receives. Add a node:test file under test/ covering these rules, and `npm test` must pass at the end.
