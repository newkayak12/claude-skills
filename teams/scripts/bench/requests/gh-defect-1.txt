In this empty Node 22 project (only a README.md exists), build a pagination helper as an ES module with no dependencies. Create package.json with `"type": "module"` and a `test` script `node --test`. Create src/paginate.mjs exporting `paginate(items, page, pageSize)`. page is 1-based. To protect the server, pageSize must never exceed 50: a larger pageSize is clamped to 50. Every call must return exactly pageSize items from the requested page whenever enough items remain, so `paginate(items, 1, 100)` over 500 items returns 100 items. Fewer items are returned only on the last page, and a page past the end returns an empty array. Add a node:test file under test/ covering these rules, and `npm test` must pass at the end.
