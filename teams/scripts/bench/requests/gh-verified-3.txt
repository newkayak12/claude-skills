In this empty Node 22 project (only a README.md exists), build a bill-splitting helper as an ES module with no dependencies. Create package.json with `"type": "module"` and a `test` script `node --test`. Create src/split.mjs exporting `splitCents(total, weights)`: total is a non-negative integer number of cents and weights is an array of non-negative numbers. It returns an array of integer cent amounts, one per weight, proportional to the weights, whose sum is exactly total. Use the largest remainder method: give each share the floor of its exact portion, then hand the leftover cents one at a time to the shares with the largest fractional remainders, and on equal remainders the earlier position wins. A share with weight 0 is always 0. It throws a RangeError when total is negative or not an integer, when weights is empty, or when the weights sum to 0. Add a node:test file under test/ covering these rules, and `npm test` must pass at the end.
