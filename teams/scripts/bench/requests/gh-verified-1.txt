In this empty Node 22 project (only a README.md exists), build a small slug helper as an ES module with no dependencies. Create package.json with `"type": "module"` and a `test` script `node --test`. Create src/slug.mjs exporting `slugify(text)` with these rules: the result is lowercase; letters with accents become their base letter (é becomes e); every run of characters that are not a-z or 0-9 becomes a single hyphen; the result has no leading or trailing hyphen; the result is at most 40 characters long, and if cutting at 40 characters leaves a trailing hyphen, that hyphen is removed too; empty input or input with only symbols returns the empty string. Add a node:test file under test/ covering these rules, and `npm test` must pass at the end.
