This small Node 22 project has an almost empty src/. Do three steps in this order. Step 1: src/chunk.mjs exporting `chunk(items, size)`: split an array into consecutive arrays of at most `size` items (chunk([1,2,3,4,5], 2) gives [[1,2],[3,4],[5]]; an empty array gives []). Step 2: src/unique.mjs exporting `unique(items)`: a new array with duplicates removed, keeping the first occurrence of each value in its original order (unique([1,2,1,3,2]) gives [1,2,3]). Step 3: src/groupby.mjs exporting `groupBy(items, keyFn)`: a plain object mapping each key keyFn returns to the array of items with that key, in input order (groupBy(["a","bb","cc"], s => s.length) gives {1:["a"],2:["bb","cc"]}). Add a node:test file under test/ for each step. While you work, keep PROGRESS.json in the workspace root up to date so someone reading only that file can tell where the work stands: a JSON array with one object per step, each with the fields `step` (the module name: chunk, unique or groupby), `stage` (the stage the step is in, for example plan, implement, test or done), `owner` (who is doing it), `state` (pending, running, done or blocked) and `next` (what happens after it, "none" for the last step). Write each step's entry when the step starts and update it as the step moves; when you finish, all three entries are `done`. Keep the change to what is asked.
