This small Node 22 project has an almost empty src/. Do three steps in this order. Step 1: src/slugify.mjs exporting `slugify(text)`: lower-case the text, turn every run of non-alphanumeric characters into a single "-", and strip leading and trailing "-" ("Hello, World!!" gives "hello-world"; "" gives ""). Step 2: src/truncate.mjs exporting `truncate(text, max)`: return the text unchanged when its length is at most max, otherwise its first max-1 characters followed by "…" (truncate("hello world", 5) gives "hell…"). Step 3: src/wordcount.mjs exporting `wordCount(text)`: the number of whitespace-separated words, 0 for an empty or blank string. Add a node:test file under test/ for each step. While you work, keep PROGRESS.json in the workspace root up to date so someone reading only that file can tell where the work stands: a JSON array with one object per step, each with the fields `step` (the module name: slugify, truncate or wordcount), `stage` (the stage the step is in, for example plan, implement, test or done), `owner` (who is doing it), `state` (pending, running, done or blocked) and `next` (what happens after it, "none" for the last step). Write each step's entry when the step starts and update it as the step moves; when you finish, all three entries are `done`. Keep the change to what is asked.
