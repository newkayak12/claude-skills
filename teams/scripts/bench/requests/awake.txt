Build a small macOS menu-bar app that keeps the Mac awake only while Claude Code is actually working, and lets it sleep otherwise. Always-on sleep prevention is the problem being solved: a caffeinate left running or an "always awake" toggle keeps the laptop up all night for nothing, and a laptop that sleeps mid-session kills a long Claude Code run. "Working" means a Claude Code session is running and has shown activity recently - decide how to detect that on this machine (for example the claude processes and the session transcripts under ~/.claude/projects) and state the idle timeout you chose and why. While working, hold a power assertion that prevents idle system sleep, and release it promptly once nothing is working; do not keep the display awake unless the user opts in. A crash of the app must never leave the Mac stuck awake, and nothing may need admin rights. The menu shows why the Mac is awake (which session) or that sleep is allowed, and offers a pause. Only the Command Line Tools are installed, not Xcode: build it with Swift Package Manager, put the detection and the awake/sleep policy behind tests that run with `swift test`, and write a README a new user can follow from clone to running app.
