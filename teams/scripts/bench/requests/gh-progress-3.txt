This small Node 22 project has an almost empty src/. Do three steps in this order. Step 1: src/clamp.mjs exporting `clamp(n, min, max)`: n limited to the range min..max (clamp(5, 0, 3) gives 3, clamp(-1, 0, 3) gives 0, clamp(2, 0, 3) gives 2). Step 2: src/sum.mjs exporting `sum(list)`: the total of an array of numbers, 0 for an empty array. Step 3: src/mean.mjs exporting `mean(list)`: the arithmetic mean of an array of numbers, `null` for an empty array (mean([2, 4]) gives 3). Add a node:test file under test/ for each step. While you work, keep PROGRESS.json in the workspace root up to date so someone reading only that file can tell where the work stands: a JSON array with one object per step, each with the fields `step` (the module name: clamp, sum or mean), `stage` (the stage the step is in, for example plan, implement, test or done), `owner` (who is doing it), `state` (pending, running, done or blocked) and `next` (what happens after it, "none" for the last step). Write each step's entry when the step starts and update it as the step moves; when you finish, all three entries are `done`. Keep the change to what is asked.
