In this empty Node 22 project (only a README.md exists), build an interval helper as an ES module with no dependencies. Create package.json with `"type": "module"` and a `test` script `node --test`. Create src/interval.mjs exporting `mergeIntervals(list)`, where list is an array of `[start, end]` number pairs. It returns a new array of merged intervals sorted by start. Intervals that overlap or touch (one ends exactly where the next starts) are merged into one, and an interval fully inside another disappears into it. A pair given as `[end, start]` (start larger than end) is treated as `[start, end]`. An empty list returns an empty list. The function must not modify the list it receives or any pair inside it. Add a node:test file under test/ covering these rules, and `npm test` must pass at the end.
