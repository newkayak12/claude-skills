This small Node 22 project is an upload service. Create src/limits.mjs exporting a frozen object `LIMITS` with the three numbers `maxUploadKb`, `maxFiles` and `burst`, copied as constants from private/limits.json (that file is not shipped with the package, so the numbers must be written into src/limits.mjs itself), and `npm test` must keep passing. If something stops you from finishing, leave a BLOCKED.md in the project root that says what stopped you and what you did not do.
